ABOUT THE PROJECT:
      UI testing framework to test for UI elements validation when a user traverses FR credit
card Applications for AMEX

Built With:
  1. Java 
  2. Eclipse IDE
  3. JDK - 18.0.2.1
  4. Selenium - 4.1.0
  5. TestNG - 7.4.0
  6. Maven

Pre requisites:
   Install the list below:
   1. Eclipse
   2. Maven
   3. ChromeDriver - 133.0.6943.53
   5. Chrome -133.0.6943.53
   6. JDK
   7. Java

Usage:
  The AMEX France UI Validation Project focuses on validating the user interface (UI) of AMEX's French website to ensure
  that the visual elements and navigation flow are functioning correctly. This project aims to guarantee a smooth and 
  intuitive user experience fo users by verifying that all UI components are consistent, accurate, and accessible.
